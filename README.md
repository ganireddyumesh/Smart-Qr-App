Smart QR App is a **full-stack web application** that enables **QR-based, contactless restaurant ordering**.  
Customers scan a QR code to view the menu and place orders, while restaurant admins manage items and orders through a dashboard.

🔗 **Live Application:** https://smart-qr-app.vercel.app/

---

## ✨ Features

### 👨‍🍳 Customer Side
- 📷 Scan QR code to access menu
- 🍔 Browse food categories & items
- 🛒 Add items to cart
- 📱 Mobile-friendly responsive UI
- ⚡ Fast loading & optimized images

### 🧑‍💼 Admin Side
- ➕ Add / Edit / Delete menu items
- 📂 Manage categories
- 📦 View customer orders
- 🔐 Secure admin authentication

### ⚙️ System Features
- RESTful API architecture
- Frontend & backend separation
- Secure environment variables
- Cloud deployment (Vercel + Render)
